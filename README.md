# Phao_PRO192

Cheat sheet tra cứu cho bài thi thực hành **PRO192 (Java)** theo hướng keyword tiếng Anh trong đề → cách hiểu → câu lệnh Java → code mẫu.

## Nội dung

- Tra cứu keyword tiếng Anh nhanh (so sánh, số lượng, String, Collection, OOP).
- Đọc UML, dựng class, constructor, getter/setter.
- String, Character, Number, Condition, List/ArrayList, Array, Inheritance, Interface.
- Scanner, format output, StringBuilder, lỗi compile/runtime thường gặp.
- Boundary tests, checklist phòng thi, Case Cookbook.
- **Mục 59: Độ dài chuỗi (`String.length()`) – toàn bộ thao tác.**
- **Mục 61: Import cho parameter/return và format `formatted` / `rounded` / `truncated` / percent.**

Mọi mã Java trong tài liệu ưu tiên cú pháp **Java 8 / JDK 1.8**.
